# 文风选择与基线

文风须作者明确选定。本项目自带五档定位、写作提示与数字形状锚，不需要从其他项目
读取文风文件。档名是稳定标识，并不限制小说题材；具体声线由契约与作者选择决定。

每档都有独立完整文件，位于 `references/styles/`，包含执行摘要和离线参考分析。

`scripts/novel_ledger_lite/contracts.py` 的 `STYLE_CATALOG`，选项通过 `pipeline.style_board()` 返回。

## 外部文风档案

作者也可提供任意来源的 UTF-8 Markdown 文件，以 `contract.style_source` 登记实际路径。
没有固定文件名、生成工具或强制模板。建议写明声线、视角、句段节奏、对白、情绪表达、
少量经授权样例及不应出现的习惯。文件全文作为写作依据，不自动解析其中量化值。
一个完整自带样例见 [../tests/fixtures/style_archive_sample.md](../tests/fixtures/style_archive_sample.md)。

开书或显式换档时读取并冻结文件内容，文件之后改写或移动不影响当前冻结版本。
`style_source` 非空时使用外部档案，`style_profile` 若同时存在只保留作数字锚标识。

## 派工与换档

- 内置档在开书或显式选档时读取并冻结实际文件；缺文件会拒绝，不以数值锚代替写作规格。
  每章 `style_guide` 携带所选档案的执行摘要，默认必读；完整 `style_reference` 作为可选记录
  按需补读。执行摘要可在宿主确认当前会话已加载准确哈希后复用，换会话默认补齐。
- 未选定文风时拒绝派工和直提，返回 `style_not_selected` 与内置/外部选项；由宿主请作者选择。
- 信封 `style` 与简报使用同一套声线、章纲节奏、容差与当前基线。
- 外部档案默认每章作为 `style_archive` 必读；仅宿主确认当前会话已加载准确内容哈希后省略正文。
- `pipeline.recontract_patch(book, source=作者决定, style_profile=档名)` 或 `style_source=路径`
  从下一待写章切割旧章基线。只传内置档名会清除旧外部源；同路径外部档案也可显式更新。
  `contract_changes` 保存来源与前后契约，各章提交时契约版本保留供验链。

## 数值检查的含义

最近五章已提交正文的逐指标中位为滚动锚；只有一章时用它作为开篇参照；没有近期样本
则用内置注册锚。外部档案未带内置档名且无已提交样本时不做形状比较。

`style_guard=observe` 默认只记录形状变化，`strict` 才拒绝超过已设容差的变化；
章纲明确声明的对白比例和章内高重复率仍会检查。代词分布仅作观察，不能判定实际视角。
样本字数量级与句数须足以比较；数值一致不保证文学质量。
