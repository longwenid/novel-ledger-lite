# lite-2.2.0 发布验收

日期：2026-11-09。优先级：忠于作者确认的设计、完整保留关键材料、真实独立审读，再控制重复与材料量。

## 发布门槛与证据

- 全量 pytest：269 项通过，含隔离复制目录、标准库运行和 12 项真实客户端 Node 子测。
- 历史保护：已写章纲和已使用节点/承诺定义不可改写；合法未写尾部修订保留历史与组首快照，旧包失效。
- 保存：bundle 与 store 两入口都先完整序列化，再同目录临时落盘、fsync 和原子替换；write/fsync/replace 故障注入均保留旧档且清理临时文件。
- 独立审读：所有新提交要求 review_ref。完整材料、稿件、申报、契约、章纲、前态和前章链必须匹配；自审、缺料、不确定、漏项、旧引用、异步旧包报告、链头回滚和文档丢失均拒绝。
- 报告不可重放：每轮请求有独立 attempt，报告必须回传对应 request_ref，每轮只登记一次；真正再审使用新请求和真实重新阅读。
- 材料完整性：长期未变的事实、资产、关系与当前人物状态、点名/pinned、未兑承诺、历史原文保留；依赖不完整继续保守全量。不设固定 Token 裁切预算。
- 界面完整性：3000 章大视图与 6004 行正文完整重组；UTF-8 分片、顺序、路径、版本、逐块及整体 SHA-256 校验；缺块、篡改或截断明确报错。无摘要、知情或伏笔内容长度裁剪。

对应回归见 test_release_persistence_history.py、test_content_review.py、test_content_review_bindings.py、test_package_context_scope.py、test_independent_content_acceptance.py 和 test_ui_reader.py。

## 真实正文与语义反例

原演示存在来源证据和因果缺料。独立读者对其作出 needs_material，未颁通过凭证；原输入和实际报告保存在 fixtures/example-review-before.json，当前门禁复验会停在第 0 章。

准备者另行修订仓库演示设计，先冻结规则、来源真相、逐章证据、查单收费、责任后果与终态，再按设计写正文。未改动任何用户作品。

另一位独立读者实际阅读四份签发包及四章全文，逐章核对全部事件后记录报告、提交并推进。四章共 855 汉字，最终 verify_full 与保存重载通过，无未兑承诺。初始准备者又独立重建设计和正文，确认没有为了通过审读而修改冻结输入。冻结设计、实际文风材料、稿件指纹及实际报告保存在 references/example_project.json；run_example 只对这些固定且指纹一致的样例复用报告，不给任意稿件自动批准。

另一次独立读者中性比较三个候选，原事件引文和 clean 申报均保留：

## 长程与复现

默认基准现在执行 chapter_package → validate → 合成测试审读凭证 → 带 package_ref/review_ref 的 submit。本轮原计划每章 3500 汉字、3000 章、100 卷。确认完成至第 1900 章（665 万合成汉字），第 1500 章保存重载后继续运行通过；随后用户明确验证规模已足够，要求收尾发布，已停止长测。阶段记录在 benchmarks/long_run_package_v220_stage_1900.json，含对应引擎源码指纹和实际进度。3000 章末尾全量验收及定点恢复未执行，不能宣称本轮 3000 章已全过。完整重放/恢复能力另由已完成的单元、集成与真实四章示例验证。

```bash
python3 -m pytest tests -q
python3 scripts/run_example.py
python3 tests/benchmark_long_run.py --delivery package --chapters 3000 --output /tmp/novel-ledger-package-full.json
```

合成测试凭证只覆盖机械协议、存储与负载，不能用于实际作品，也不是真实文学创作或语义评价。真实语义实验是上述固定短章、缺料例与两个矛盾反例。

## 分发与边界

引擎版本 lite-2.2.0，配套插件 0.2.0。账本/bundle 为 /2，签发后尚无审读为 store/3，登记审读后为 store/4；旧 store/2、store/3 可加载继续，但后续提交仍要求审读，缺凭证的旧历史不能宣称完整审读验收通过。

新导出为 view/2 清单加 chunks 分片，须随新版插件使用并保留完整导出目录；新版插件兼容旧 view/1。客户端已用模拟宿主验证真实读取实现，未在实际 DSH 宿主现场安装验证。派生旧分片暂留以兼容正在读取旧清单的界面，可删除整个派生目录重新导出。

门禁验证所登记报告的完整性、独立身份标识及其对象绑定，不是自然语言真伪检测器。宿主必须实际调用不同于写作者的独立读者并如实记录；没有读者或存在不确定性时停写。不能以测试全过或哈希正确承诺任何模型或读者对任意小说绝对零误判。
